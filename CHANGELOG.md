# Changelog

## [0.1.0] - 2026-04-05

### Added
- Initial release
- AI-powered trapping builder using Claude API
- Support for all WFRP4e item types: trappings, weapons, armour, ammunition, containers
- Full active effect generation: characteristic modifiers, skill bonuses, SL bonuses, conditions, healing, movement, fate/fortune/resolve/resilience, advantage
- Preview card with effect details before item creation
- Create items to world Items directory or directly to actor inventory
- "Create Trapping (AI)" button injected into actor sheet Trappings tab
- Module settings for API key, model selection, default item type
- FoundryVTT V13 compatible (ApplicationV2 + HandlebarsApplicationMixin)
